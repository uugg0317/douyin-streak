# 本机抖音登录态获取流程

公开版管理后台免管理登录。此目录负责使用者自己的抖音账号登录，输出 Playwright `storage_state`，供本地服务读取。

1. 启动干净的 Chromium 上下文，打开抖音页面。
2. 使用者在浏览器窗口或二维码截图中完成自己的抖音扫码登录。
3. 脚本轮询浏览器 Cookie，检测到非空 `sessionid` 后保存登录态。
4. 使用者把本机生成的 JSON 导入对应账号；多账号后台固定目标账号，待使用者核对后再确认保存。

登录由浏览器和抖音页面完成，脚本没有独立的 ticket 换 Cookie 接口，运行无需本项目的管理密码。

`state.json` 包含账号 Cookie 和网页本地存储；`extract_qr.png` 是运行截图，可能包含登录二维码。它们已被根 `.gitignore` 排除，不随公开源码提供。日志只展示 Cookie 名称、数量或值长度，不输出 Cookie 值。

完整参数和安装方式见 [使用说明](README.md)。
