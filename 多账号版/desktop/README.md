# 多账号 Windows 桌面版

在 `多账号版/` 目录执行：

```powershell
python desktop/build.py
```

构建脚本会建立独立环境、安装桌面依赖并准备 Chromium。完成后分发构建生成的整个 `DouyinStreak` 文件夹，不能只复制 `.exe`。

双击程序后会启动本机服务并自动打开浏览器，直接进入多账号管理后台，无需管理密码。服务只绑定 `127.0.0.1`；8000 被占用时会自动选择后续可用端口。托盘可打开后台、重启或退出服务。

首次运行的 `.env` 只包含本机监听地址、模式和时区，抖音账号需要使用者在后台自行登录。构建目录不会收集真实 `.env`、Cookie、账号目录、好友台账或运行日志；请分发干净的构建产物。
